## Step-by-Step Setup

### 1. Create Project Folder
```bash
mkdir stock-screener
cd stock-screener
```

### 2. Initialize React App
```bash
npx create-react-app .
```

### 3. Install Required Dependencies
```bash
npm install axios recharts date-fns
```

### 4. Get Free API Key
1. Go to https://www.alphavantage.co/support/#api-key
2. Enter your email and get your FREE API key
3. Limit: 25 API calls per day (we'll optimize for this)

Alternative: https://finnhub.io/ (60 calls/minute free)

### 5. Create .env File
In the root directory, create a file named `.env`:
```
REACT_APP_ALPHA_VANTAGE_KEY=your_api_key_here
```

Replace `your_api_key_here` with your actual API key.

### 6. Update .gitignore
Add to `.gitignore`:
```
.env
node_modules/
build/
.DS_Store
```

## Troubleshooting

### "API key invalid"
- Check your .env file
- Ensure no spaces around the key
- Restart the dev server after changing .env

### "CORS error"
- Alpha Vantage supports CORS
- If issues persist, try Finnhub API instead

### "Rate limit exceeded"
- You've hit the 25 calls/day limit
- Wait 24 hours or get another free key
- Results are cached, so refresh the page to see cached data

### Slow loading
- API calls take 1-2 seconds each
- With 50 stocks, initial load takes 2-3 minutes
- Results cached for 24 hours
